How I Take Notes

Author Christopher Klein
Published November 5, 2025 Updated November 5, 2025
Tools Systems Writing

Overview

Not a productivity guide. A description of what I actually do: the tools I use, the habits I've kept, and the ones I've abandoned. Mostly an exercise in noticing what works and not pretending it's a system.

What I Actually Use

A plain text file for daily notes. A pocket notebook for things that need to be written by hand. Occasional voice memos when I'm moving. Nothing else has stuck for more than three months.

I've tried most of the popular note-taking applications. Some of them are genuinely impressive. None of them changed how I think, which is the only measure I care about. They changed how I organised my thoughts after having them, which is useful but not the same thing.

The Plain Text File

One file per day. Date at the top. No headers, no categories, no backlinks. Just whatever I'm thinking about or working through. I don't review these files. I don't index them. I write in them because the act of writing is useful, not because the notes are useful.

This sounds wasteful. It might be. But every time I've tried to build a system that treats notes as assets to be retrieved later, I've spent more time maintaining the system than using it.

The Notebook

Narrow, unlined, no brand. I fill one every two to three months. Meetings go here. Sketches go here. Lists that need to be written slowly. The act of using a pen is different enough from typing that it's worth having both.

What I've Abandoned

Tags. Folders. Bidirectional links. Weekly reviews. Zettelkasten. The second brain. Not because these things are wrong — many people clearly find them useful — but because the overhead of maintaining them was always higher than the value I got from them.

A system you don't use is worse than no system, because it makes you feel like you should be using it.

— Something I wrote down once and actually kept
