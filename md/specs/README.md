# Specs

This folder holds spec docs for upcoming Claude Code prompts. Chris drafts each spec in the claude.ai Project (full reasoning, findings, and decisions live there), then drops the finished file in here before the matching prompt runs, so the spec is committed to the repo alongside the change it describes instead of existing only outside version control.

**Naming convention:** `YYYY-MM-DD-short-name-spec.md`.

Specs dated before 2026-09-29 were never committed to this repo — they exist only in the claude.ai Project. If a prompt cites one of those by filename, treat the pasted prompt itself as authoritative rather than treating the missing file as a blocker (see md/PROMPT-GUIDE.md).
