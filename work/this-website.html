This Website

User Experience Web Development
Role Designer / Developer
Timeline June 2026 – Present
Tools HTML, CSS, JavaScript, Claude Code, Figma

Overview

With Claude and Claude Code, I created this Website to rid myself of Squarespace, learn how to utilize AI, learn about web development, and implement Accessibility standards.

The Problem

Squarespace handled hosting and templating, but it imposed hard constraints on layout, limited CSS control, and generated markup I couldn't own or audit. Every accessibility decision was mediated by a platform that didn't prioritize it. I wanted to learn the underlying craft properly and build something I could iterate on without platform friction.

Process

The site is built as plain HTML, CSS, and JavaScript — no frameworks, no build tools, no preprocessors. Design tokens are maintained as CSS custom properties. Components are hand-coded against a written spec. Claude Code handles the mechanical transfer from design decisions to implementation.

Design System

A full design token set — colour, spacing, typography, border, and motion — is defined in a single CSS file and documented in a paired design system reference. Every value in the codebase traces back to a named token. Figma Variables mirror the token set for design work.

Accessibility

WCAG AA is the floor, not the target. Every component was reviewed against WCAG 2.1 criteria. Focus management, keyboard navigation, and screen reader output were tested explicitly. The archive filter drawer required a full inert-attribute solution to eliminate focus leakage behind an open overlay.

Outcome

A fully owned, version-controlled personal site — deployed to Netlify, iterating continuously. Every decision is documented in the codebase and can be audited, reversed, or explained.
