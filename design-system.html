Section 8 — Tag & Tag-Chip Components

.tag — teal outlined style (the live default accent; see Section 1), transparent background. On hover, border and text brighten to the lighter teal and background fills with the page base colour. Tags are links navigating to archive.html filtered by tag slug.

Section 10 — In-body Images (Standard Page body content)

Added 2026-08-18. .standard-page-content img — full width, natural aspect ratio, border-radius: var(--border-radius-md), nothing else: no background, border, padding, or shadow — not a card. Captioned images use <figure> + <figcaption class="standard-page-caption"> — the same caption class the page banner already uses, not a second caption style. Uncaptioned images are a bare <img>. Both require alt text and loading="lazy". No lightbox/click-expand — that's a separate, not-yet-scoped feature. Shown unframed below (no demo box) — a real entry page has no wrapper around this either.

Section 11 — Tables (Standard Page body content)

Added 2026-08-18. .standard-page-content table/th/td — capped at the same 65ch reading column as everything else in body content (override per-instance if a table genuinely needs more room), scrolling horizontally rather than reflowing on narrow viewports. th reuses the same label treatment as .standard-page-details-label, by value not by selector.

Section 13 — Code Block

Background uses --color-code-bg (background-subtle). Left border uses --color-code-border (accent-primary). Monospace font. Inline code and block pre/code both styled.

Use aria-current="page" on the active nav link after injection to mark the current page for screen readers.

/* Set aria-current on the matching nav link */
function setActiveNavLink() {
    const page = location.pathname.split('/').pop() || 'index.html';
    document.querySelectorAll('.nav-links a').forEach(link => {
        link.toggleAttribute('aria-current',
            link.getAttribute('href') === page
        );
    });
}
